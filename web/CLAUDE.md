# web/CLAUDE.md

Multi-page Vite + React SPA (no router library), Node 22, `pnpm@12.14.0`. Plan §6.
Pages: `index.html` (landing + "Try as" picker), `studio.html` (`?engine=scripted|live`, `?demo=DEMO-01`,
`?ff=<flag>`), `dev.html` (block + stage gallery), `ar.html`.

## Pins: DO NOT UPGRADE

- `three@0.187.0`, `@react-three/fiber@9.8.2`, `@react-three/drei@10.7.9`
- `react@~19.3`, `react-dom@~19.3` (R3F 9.8 needs `<19.4`)
- **`typescript@~5.9.3`. Never TypeScript 7** (breaks `openapi-typescript` and `typescript-eslint`).
- Deps are frozen after the skeleton PR; never hand-edit `pnpm-lock.yaml` (resolve with `pnpm install`).

## Styling and UI

- **Tailwind v4** via `@tailwindcss/vite`. Design tokens live in CSS `@theme`; there is **no** `tailwind.config.js`.
- shadcn/ui components go in `src/components/ui/`, added with the CLI only.
- **Desktop first, mobile last (L3):** check at 1440×900 and 1280×800. Flex/grid, no fixed pixel widths, no
  mobile-only code before the Final phase.
- Unfinished UI goes behind `?ff=<flag>`.

## Feature folders

Code lives in `src/features/<feature>/` (`landing, studio-shell, personas, chat, genui, result, form, flight,
stage3d, tinker, mascot, ar`). Stay inside your lane's folders. Shared: `src/api/`, `src/store/`, `src/host/`.

## Add a gen-UI block = 3 new files, nothing else

1. `backend/app/schemas/ui/<name>.py` (generates the `ui_<name>` tool and the `UIBlock` member)
2. `web/src/features/genui/blocks/<name>.tsx`, exporting `{ type, Component }` (collected by `import.meta.glob`)
3. `fixtures/ui/<name>.json` (shown in `dev.html`)

Never add a central switch or map. Props are `Extract<UIBlock, {type: '<name>'}>`.

## Contracts and state

- `src/api/schema.gen.ts` is generated by `just gen` (gitignored). Never edit or commit it.
- Chat messages render **plain text** only (bold + line breaks). No HTML or URLs from the model; media uses ids
  from `fixtures/*.json`.
- `store/session.ts` keeps the `FittingState` with the **highest `version`**, from SSE `state` events and REST.
- Never hardcode the API port: the dev server gets `API_PORT` from `just dev` (web runs on `API_PORT + 1`).

## 3D rules (L1, enforced in review)

- `<Canvas frameloop="demand" dpr={[1, 2]}>`, loaded with `React.lazy` so chat renders first.
- While dragging a tinker slider, mutate three.js refs and call `invalidate()`. **Never `setState`/zustand per tick.**
- Reuse geometries/materials; asset contract is issue #3 (`assets/clubs/manifest.json`, `HoselSocket`).

## Check

`pnpm check` (or `just check` from the root): gen, typecheck, lint. Then look at it in `just dev`. No tests (L17).
