Switching rules
  • Default is Tap. The first card is always a full component.
  • Two free-text answers in a row switch to Type: the next questions arrive as text with a small inline confirm chip.
  • Using the mic switches to Talk: same chips, the fitter can read its reply aloud.
  • A card is always one tap away: "Show options" under any text question brings the full card back.
  • Whatever they type is parsed for every field at once, so one long message can skip several cards (see 2b).
