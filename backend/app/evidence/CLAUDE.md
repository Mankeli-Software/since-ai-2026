# backend/app/evidence/CLAUDE.md

Pure layer: parsers, plausibility rules, inverse-variance fusion. **No I/O, no LLM, no `httpx`.**
Bytes or dicts in, `Shot`s / `Flag`s / `FusedEstimate`s out (plan §5).

## Non-negotiables

- **The LLM never judges plausibility.** Every flag comes from a deterministic rule here; the model only phrases it.
- **No free text into the chat.** Tool output is numbers + `FlagCode` enums. Cap any string read from a CSV or
  screenshot to `^[\w %./°-]{0,32}$`. Never store raw uploads.
- All TrackMan data is synthetic (L6). The link importer (`trackman_fetch.py`, `trackman_report.py`) is cut: don't build it.

## Add a parser (`parsers/<name>.py`)

```python

    """Pure. Output uses the pack's shots.csv columns; convert to mph / yd / deg here."""
```

- Header aliases go in `parsers/aliases/<vendor>.json` (one file per launch monitor), never in a shared dict.
- TrackMan CSV: parse the units row; group by a `Club` column if present; empty cells stay empty.
  **Dynamic Lie is absolute** (≈ 58–66°): if values sit in 45–80°, `impact_toe_up_deg = dynamicLie − club_lie`
  (62° + built lie for Takomo test clubs, 62° for an own club) before S1, or S1 rejects every real shot.
- `parse_trackman_csv(raw, club=...)` (#30) returns `TrackmanCsv {shots, clubs, dropped_clubs, vendor, units_seen,
  dynamic_lie_absolute}`. Routes: `POST /imports/trackman-csv` (pending import) and the generic
  `POST /imports/{id}/confirm`, which appends the import's `parsed_shots_json` to `FittingState.shots` and bumps
  `evidence_version`. Samples: `fixtures/trackman/` (synthetic, regenerate with its `generate.py`).
- Ball-line (`parse_ball_line`): `BallLineEvidence {readings, mean, sd, n}`; + = line leans toward the toe,
  `lie_need = −mean`. It is fused with the chart, never an override. Copy says "readings", never "shots".

## Screenshot extraction checks (`plausibility/extraction.py`, #34)

- `validate_extraction(session, *, second_read=None, shot_rules=(), club="own_7i", import_id=None) -> list[Flag]`
  runs V1 cell integrity, V2 unit labels, V3 (the caller's S rules mapped back to screen rows), V4 (S1 bounds with a
  decimal-slip suggestion, smash / face-to-path / total-vs-carry checksums, confidence < 0.8) and V5 (double read).
  Cell flags carry `shot_index = cell.row`, `field = cell.field`. `v1_schema_check(raw)` is for unparsed model output.
- **Duplicated thresholds:** the S1 bounds and the S3 / S13 / S6 tolerances are copied into `extraction.py` as named
  constants so V4 works before `shots.py` (#31) lands. When #31 lands, pass its S rules as `shot_rules=[...]` from the
  screenshot route and keep the two S1 copies in sync (or import them).
- Round stats: `parsers/round_stats.py` (`parse_round_stats` → `score_bucket_from_score` via `app.pack`) and G13 in
  its own file, `plausibility/round_history.py`.

## Severities (σ effect in `fuse.py`)

| Severity | Effect |
|---|---|
| `reject` | excluded from every estimate |
| `downweight` | σ × 2 |
| `confirm` | pending at σ × 3; the assistant asks |
| `info` | shown only |
| `unit_suspect` | source excluded until confirmed |
